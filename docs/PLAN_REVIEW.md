| 多人多段改签 | NSA Standard 两人各两段、均提前 ≥24h，每段涨 30 → 手续费 100+差价 120=应收 220 → 明确四段后一次提交 | A03、M2/M4 |
| 正负差价及税费 | 一人两段，旧价各 100，新价 130/60，费用各 25，税 +8/−5 → 应收 88、退税 5，经济净支出 83 → 分开记资金行，无 −40 抵扣 | M2/M8 扩展 |

| 整票国内国际 | STA Standard 改国内+国际段、提前 30h → 手续费 20+65=85；若改为整票取消则因含国际按国际规则，不沿用分段退费 | A05、M2 扩展 |
| 取消额度与退税 | NSA Standard 提前取消，票价 100+税 20+座位 10 → 额度 60、原路退税 20、座位不退 → 取消/额度/税消费同事务，同行不变 | A06 |
| Basic 自愿取消 | 整票完全未用，票价不可退但有明确未用税 → 说明票价为零退款、税可退，完整确认后办理 → 不能因一项不可退就丢掉税权利 | M2/M4/M8 扩展 |

| 独立退税 | 明确未用未退且不存在有效乘机权益冲突 → 单独报价/确认；事实不明或冲突 → 审核，不隐含取消 | M2/M4/M8 扩展 |
| 升档与附加服务 | 旧票费率决定本次费，候选提供全票一致价格和可转服务 → 重签保留原出票时间；混合票价/不可转服务 → 审核、不丢权益 | M2/M4/M8 扩展 |
| 误机 | 无合格保护且满足误机事实 → 剩余段暂停、票价不退、未用税仍可申请 → 不自动恢复；保护成立则先保护 | M2/M4/M8 扩展 |
| 同票/不同票并发 | 两个获授权会话同票旧版本 → 一个成功另一冲突；不同票各自版本/授权满足可分别成功 → 以 DB 结果核验 | A09 |
| 多人中一项失败 | 已选择两票，第二票无位或必要记录写失败 → 所有票/库存/钱/权益/Operation 回滚 → 收据可以保留拒绝状态，不叫部分办理 | M4 故障测试 |
| 提交后丢响应 | COMMIT 已有 Operation，页面尚未知 → 按原键/编号查当前可见结果 → 恢复一次成功，不因换键/报价过期再收退 | A10 |
| 五分钟与内部排队 | 创建后 299999ms 收到完整有效确认可进准入；300000ms 已失效 → 前者排队仍保留收到时间，但最终失权/票变化仍不提交 | C03/M8 |
| 新意图与旧确认 | 若旧确认先提交，后续轮次看到新状态；若轮次先开始，确认暂停 → 解释后可恢复，目标变化后旧报价失效 | C05/C07/M8 |
| 撤权与办理 | 撤权先提交则旧确认不能办；业务先合法提交则保留结果，后续查询仍按当前权限裁剪 → 两种顺序都不泄漏 | M3/M4 屏障测试 |
| 政策更新 | 新文件/规则校验后启用对应区间 → 提交同库选组合；不兼容重报价，未来生效不误伤此前仍适用报价 → 旧操作不重写 | C04/M8 |
| 崩溃与诊断失败 | COMMIT 前崩溃恢复为无业务变化/中断；COMMIT 后恢复原成功；诊断失败只标不完整 → 所有结果有明确事实基础 | C05/C08/M8 |

## 4. 合理性与取舍检查

- 数据库覆盖真实需要协调的模拟事实，一次短事务可实现多人原子性；模型和用户等待不占写锁。单写者限制作为容量边界公开，实施后才给实测数值。
- Submission 与 Operation 分开是为了区分“收到确认”和“真正提交”。拒绝收据保留不违背订单/资金全成或全不变。
- M2 只接可信只读事实，共享计算核心既支持 skills 又支持提交复核，避免模型算钱与多份费率漂移。
- 独立 M1 保留复用价值，业务以明确版本调用；其 CURRENT 不偷偷成为业务发布开关。每次本地进程的开销要测，不以未来规模为由预建服务平台。
- 本期不处理外部支付，故不引入分布式事务/补偿平台；将来接真实资金时不能直接宣称本地原子性覆盖外部。
- 不可自动办理不等于政策拒绝；人工路径保留权利和未知项，但不伪造审核服务或审批结果。
