## 2. 通用概念与时间（各航司 §1、§1.1，p1）

- 一个订单可含多位旅客的客票；一张旅客客票可含多个航段。航段是一段起飞和降落。
- 任一航段已飞即为旅行已开始；完全未使用客票没有已飞航段。
- 国内：航段两端均在虚构的 Republic of Aster；其他为国际。
- 改签和行李按每个航段判断国内/国际；自愿整票取消，只要任一航段为国际，整个行程按国际判断。
- 所有时间按 UTC 和实际经过时间计算；不存在夏令时调整。
- 提前窗口：距起飞至少 24 小时，含恰好 24 小时。临近窗口：大于 0、小于 24 小时。恰好起飞及之后的新自愿请求按误机处理。
- 改签参照受影响各航段当前记录的起飞时间；完全未用整票取消参照第一航段。
- 完整请求需要事实齐全、权限核验及接受报价；不完整的早期消息不保留时间资格。报价本身不改变订单。
- 所有货币为 USD；列示手续费已含该手续费相关税，不要在手续费上重复加税。单列政府税费仍单独处理。

其他要求：

- 每位旅客每个改动航段，新票价减旧票价，只收正数。票价计算排除税费和附加服务。更低票价没有退款或额度，也不能抵扣改签费。
- 按“每个航段的正差价”加总，不能先把各航段正负差价合并再取正值。

- 可以改日期/起飞时间，以座位可用为前提；更换航司、旅客或起终点不属于本自愿改签规则，须联系服务台审核。
- 可保留或升级票价类型，不得降级。本次手续费按现有票价类型，下一次申请按替换后的票价类型。
- 加购行李或较高登机行李额度本身不改变票价类型。
- 已经开始旅行但没有误机时，剩余未飞航段仍逐段按表判断；一旦有误机，其规则优先。
- 合格日期/时间改签时，未使用附加服务可在同一旅客、同一路线下免费转移，受服务可用性限制。不可提供时转人工，不自动承诺退现金（§3.2 p3）。

## 4. 自愿取消与退款（各航司 §3～§5，p3）

仅适用于选中旅客整张完全未使用客票，且不属于合格航司异常。手续费按每位旅客的整张行程计，不按航段或订单重复收。下表均为不含单列政府税费和附加服务的票价部分。

| 航司/票价 | 距首段起飞 ≥24h | 0h < 距首段起飞 <24h |
|---|---|---|
| 全部航司 Basic | 不退票价，不给额度 | 不退票价，不给额度 |
| NSA Standard | 票价减 $40，给旅行额度 | 票价减 $80，给旅行额度 |
| NSA Flex | 票价原路退，$0 手续费 | 票价原路退，$0 手续费 |
| BHA Standard | 不退票价，不给额度 | 不退票价，不给额度 |
| BHA Flex | 票价减 $30，给旅行额度 | 不退票价，不给额度 |
| STA Standard 全国内 | 票价减 $25，给旅行额度 | 不退票价，不给额度 |
| STA Standard 含国际 | 不退票价，不给额度 | 不退票价，不给额度 |
| STA Flex 全国内 | 票价原路退，$0 手续费 | 票价减 $20，原路退 |
| STA Flex 含国际 | 票价减 $50，原路退 | 票价减 $75，给旅行额度 |

共同补充：

- 合格退款/额度为 `max(合格票价 - 取消费, 0)`。手续费超过票价时不追加收差额。
- 所有票价、不可退票和误机，均可申请退回未使用的政府税费，退原支付渠道。
- 自愿取消的已购行李及座位附加服务不退。不能将整张订单付款总额直接套入票价退款公式。
- 可在核验权限后只取消其中一名旅客整张客票，其他旅客不受影响。
- 只取消部分航段，或已飞过部分行程后的退款，须人工审核，不能猜一个剩余票价。
- 原路退款回到原购买支付工具；付款人与旅行者可能不是同一人，但付款不赋予代理操作或转让机票的权利。

## 5. 正向、逆向与差额处理核对

### 5.1 正向改签

事实及权限 → 确认适用规则/时间窗口 → 查询可用新航班 → 按人按段列改签费与正差价 → 单列税费增减 → 核对附加服务转移 → 报价 → 用户确认 → 业务后端重新校验并执行。

M1 仅提供上面流程需要的条款。后续还要从订单取得准确价格、税额、服务使用状态和库存，不能由政策库编造。

### 5.2 逆向取消/退款

事实及权限 → 先检查是否航司异常 → 判断是否完全未用/是否误机 → 判断票价退款或额度资格 → 计算票价部分并保底零 → 单列原路退税及附加服务处理 → 明确去向与范围 → 用户确认 → 后端执行或转审核。

“取消已完成”和“退款已经到账”是不同事实；本政策不提供资金到账证明或支付清算协议。

### 5.3 可以计算与不能自行承诺的差额

| 项目 | 资料明确支持的处理 | 不应做的推断 |
|---|---|---|
| 单航段更贵 | 收该人该段的正差价 | 用另一段更便宜来抵扣 |
| 单航段更便宜 | 不退票价差，不发额度 | 把降价变成负费用抵扣手续费 |
| 政府税费变化 | 未使用税费增减另外收退，退款走原支付工具 | 将退税自动混入旅行额度，或擅自承诺跨渠道轧差 |
| 取消费超过票价 | 票价退款/额度为零，不追缴差额 | 产生负退款，再从旅客收一笔钱 |
| 同一取消有额度和退税 | 分别记本人旅行额度、原路现金退税 | 合并成一笔“现金退款” |
| 合格异常整票未用退款 | 全票价 + 未使用政府税费 + 未使用附加服务，原路退 | 套用普通不可退票限制或强制给额度 |
| 部分使用后的退款 | 保留适用权利并交人工核定 | 按里程、航段数或比例猜剩余金额 |
| 已退款的同一价值 | 不能再重复退款；完成退款结束该票对应改签资格 | 同时对同一价值又退款又免费改签 |

文档未明确规定跨收费项、支付工具或不同请求之间的净额结算方式。可以在解释中计算总经济变化，但执行时应保留收款、退款、额度的独立明细；是否能合成一笔支付需后续支付/业务契约明确，不能冒充政策规则。

### 5.4 数字核对例子（示例假设，不是真实报价）

1. **NSA Standard 改两段，均提前 30h**：每段旧票价 $100，新票价分别 $130、$60。改签费 `2×25=$50`，正差价 `max(30,0)+max(-40,0)=$30`，手续费与票价应收共 $80。若两段未使用税费分别多 $8、少 $5，明细为应收 $80、另收税 $8、原路退税 $5。经济净变化 $83，不等于文档保证只发生一笔 $83 支付。
2. **NSA Standard 提前取消**：票价 $100、未使用税费 $20、已购座位 $10。发放 $60 本人旅行额度；原路退税 $20；座位不退。不是现金退 $80，也不是退订单总额减 $40。
3. **手续费大于票价**：NSA Standard 提前取消，票价 $20、未使用税费 $10。旅行额度为 $0，原路退税 $10；不能额外向用户收 $20。
4. **BHA Basic 合格航司异常、整票未用**：票价 $200、税 $30、未用行李服务 $40、未用座位 $10。符合期限等条件时原路退 $280，免取消费。普通 Basic 自愿不退票价规则不适用。
5. **STA 混合航段**：Standard 同时改国内、国际一段，均提前 30h，手续费 $20+$65=$85，正差价/税另算；如果取消含国际航段的整张未用票，按国际取消规则，不把国内段单独算成可退额度。

## 6. 航司异常（各航司 §6～§6.3，p4）

- 本航司取消航段：所有票价均符合保护。
- 时刻变化：NSA/STA 相对原出票时确认的时刻绝对差 ≥120 分钟，BHA ≥180 分钟，含等于；提前和推迟都计算。
- 比较最新通知与原始出票时的时刻，不能只比较相邻两次通知。普通实际延误不应被自行等同于文档里的合格计划时刻变更，需要核对事实。
- 这些保护覆盖受影响旅程，优先于普通自愿限制、手续费与误机价值损失。
- 替代出行：同航司、同目的地、同票价类型、原出发日期前后 7 个日历日（含边界），有座时一次免费改签，不收差价。
- 完全未用的受影响行程：全票价、未用税和未用附加服务原路退，不收取消费；不可强迫旅客只接受额度。
- 已开始出行：未使用受影响部分退款权仍在，金额及附加项分配需人工审核；不承诺已飞航段退款。
- 无合适替代航班时退款选项仍在；完成退款结束被退款客票的改签资格，相同价值不能退两次。
- 通知时刻起实际经过 30 天内提出选择，含第 30 天；超期转人工，不直接批准或拒绝。
- 已接受替代出行，之后因个人原因再改变主意，按替换后的客票适用自愿规则；新合格异常产生新选择。
- 申请待处理不代表新座位已确认。酒店、餐饮、地面交通赔偿未规定。

## 7. 误机、旅行额度和人工审核

### 误机（§5 p3）

未在起飞前收到完整获授权的改签/取消申请，且旅客未乘该航班，构成误机。恰好起飞时收到新的自愿请求也按误机处理。剩余航段暂停，联系服务台后处理，没有自动恢复。普通剩余票价不退且无额度，包括 Flex；未使用政府税仍可申请退。合格航司异常优先，医疗情形可申请人工审核。

### 旅行额度（§3.1、§3.2 p3）

记在具名旅客名下，只能同一航司使用，不能转让或换现金。签发后精确经过 365 天到期，必须在该时刻之前兑换，新的旅行也必须在该时刻之前开始；恰好到期时不可用。未用完部分在到期前保留，无标准延期。

### 人工审核（§4 p3、§7.2 p5、§9 p6 等）

医疗、部分使用后退款、选段取消、混合票价、授权争议、监护、超重/超尺寸/更多额外行李、不可提供的附加服务、超异常申请期限等。人工审核不能被解释为已经批准。医疗资料应先取得安全提交路径；减免费用、现金退款或额度不保证。NSA/STA §9.1 还明确不承诺固定审核或退款处理时效；BHA 同样未提供固定处理时效。

## 8. 行李（各航司 §7～§7.3，p5）

所有旅客均有一件免费个人物品：40×30×15cm、3kg。下表登机箱额度是另加的。所有限额含等于，尺寸含把手和轮子。

| 航司/票价 | 登机箱 | 免费托运 |
|---|---|---|
| NSA Basic / Standard | 1 件 8kg | 1 件 23kg |
| NSA Flex | 1 件 12kg | 2 件，每件 23kg |
| BHA Basic | 无 | 无 |
| BHA Standard | 1 件 7kg | 无 |
| BHA Flex | 1 件 10kg | 1 件 20kg |
| STA Basic | 1 件 7kg | 国内无；国际 1 件 20kg |
| STA Standard | 1 件 10kg | 国内 1 件 20kg；国际 1 件 23kg |
| STA Flex | 1 件 12kg | 国内 2 件、每件 20kg；国际 2 件、每件 23kg |

登机箱均不得超过 55×35×25cm；托运行李三边和不得超过 158cm。重量和尺寸都必须满足，不能合并为一件更重行李，不能跨旅客共享额度。

| 加购 | 收费与范围 |

| NSA 额外托运 | 每人每段 $45，1 件，23kg/158cm |

## 9. 身份、代理渠道与确认（各航司 §8、§8.1，p6）

- 具名成年旅客经过身份和预订验证后可以办理自己的票。
- 订单号、同姓、持有付款信息均不是授权；付款人/主预订人不能据此查看或改退其他成年旅客的私有客票。
- 代办需书面授权，明确代理人、订单号和允许动作，并核验双方身份；监护需证据并人工核验。
- 不通过未经验证的渠道传送完整卡号或证件。文档中的网站和邮箱是虚构联系方式，不可作为真实服务承诺。
- 代理商出票通常联系出票代理；航司服务台可审核异常协助，但代理退款经出票代理路由回原支付方式。
- 报价需确认才执行。完整请求收到时间决定窗口，不是第一次表达意向的时间。

## 10. 必须保持未知的内容

- 宠物、贵宾室、会员权益、无人陪伴未成年人服务：文档 §10 明示未覆盖，缺规则不意味着允许或禁止。
- 危险品、特殊设备具体接受标准，超重/超尺寸收费和必然接受承诺。
- 银行到账日期、真实支付渠道手续费、跨渠道自动轧差、退款撤销后的重新扣款流程。
- 历次已支付改签手续费如何追溯退还、已经退过的税额和真实剩余可退金额；需要政策补充或订单/支付事实，不能从原始付款总额猜。
- 历史政策缺失时期、未提供的其他航司规则、现实世界法规补偿。
- 医疗一定免手续费、人工一定批准、酒店一定赔偿、未确认座位一定有位。

## 11. 从资料到业务模块的约束

本知识库只发布 `evidence_only` 版本。每条输出附来源和业务判断所需事实；没有执行权限，也没有输出一个可直接扣款的最终报价。

后续规则模块必须绑定这份来源版本并独立验证金额、资格和资金明细。政策变化时，资料与业务规则不得分别启用而产生不一致。对具体订单事实不足时，先补充事实；政策未规定时，明确说明或转审核。
