## 做了什么

围绕项目提供的三份虚构航司PDF，实现简单网页客服：政策与行李咨询、注册登录、授权查票、多人改签、取消和适用退款。先补齐条件、展示来源与逐项金额，再由用户明确确认；订单、库存、账本和额度在本地事务中保存，重复提交与断网恢复不会重复办理。

可选服务试用补充了样例票授权、模拟客服接单/补充/转办、订单和退款分别跟进、按预算与到达时间比较同行方案，以及航变提醒。模型使用gpt-5.6-sol理解意图和选择工具；费用、UTC时间、权限与最终提交由代码控制。证据不足时说明未知，咨询关闭不等于批准退款。

## 怎么启动

macOS解压后双击 **Start.command**；macOS/Linux终端也可运行 **bash start.sh**。需要Python 3.10+和npm。脚本使用Node24，必要时下载固定版本到npm缓存，不替换系统版本；首次联网安装依赖，随后自动构建并打开网页。

默认从3000起选择空闲端口并开启服务试用，账号和客票保存在var/interview.sqlite。再次启动保留数据。保持终端打开，Ctrl+C停止；bash start.sh --classic可启动原作业模式。Windows原生未验证。

公开仓库经所有者明确授权附带 Right Codes 演示 Key，保存在 .env.rightcodes.local，可直接启动。所有者已将供应商额度上限调整为 3 美元；剩余额度未知。启动不调用收费模型，聊天会消耗供应商额度；项目预算配置不负责限制扣费。失效或耗尽后请在本地更换自己的 Key，不要提交私用凭据。

## 包内资料与边界

包含代码、锁定依赖、原题和政策、总计划/共同契约/M1–M9模块计划、测试与执行轨迹，以及脱敏会话HTML/Markdown/JSONL和两张用户截图。会话快照截止本次打包请求；密钥在会话中脱敏，公开仓库单独附带所有者授权公开的演示配置，并保留空白配置模板。不包含隐藏推理、内部提示、原始工具日志、其他项目记录或运行中的用户数据库。

尚未接入真实航司、银行、生产身份认证或真人客服；模拟回执不代表实际到账。复杂联程、额度兑换、真实支付补偿、外部通知和多节点运营未实现。原题六小时上限未满足，也未记录可核实的精确人工工时。本项目使用AI协助开发，提交者应能解释方案并复现结果。

建议先体验“行李咨询 → 林怡取消CANCEL-NSA-A → 已授权代理多人改签”，再看服务试用。初始取消样例为额度60美元和原路退税20美元，不能理解为现金退80美元。计划与代码对应关系见docs/DELIVERY_BASELINE.md，会话说明见session/README.md。
