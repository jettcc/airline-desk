# M6：简单网页聊天计划

状态：2026-09-20，首版已实现并进入逐项交付复核，实际覆盖见 [DELIVERY_AUDIT](../DELIVERY_AUDIT.md)。本文保留已确认设计与验收要求；当前实现、测试结果和未覆盖边界分别见 [DESIGN](../DESIGN.md)、[VALIDATION](../VALIDATION.md)，不以计划预期替代实际通过。

## 目标与页面范围

让用户从自然语言需求完成政策咨询、选择获授权客票、查看方案、明确确认和查证结果。页面随时说明当前身份、操作对象、金额去向及是否已经执行。支持中英文、键盘操作、桌面和窄屏布局，视觉简洁；不做管理后台、营销页面或真实支付表单。

采用 React + TypeScript + Vite，构建后由同源服务提供；组件按业务卡片拆分，不引入复杂状态平台。服务端事实是依据，浏览器只保存显示/输入状态。

## 页面及组件

| 组件 | 用户看到的内容 |
|---|---|
| 顶部状态 | 模拟服务标识、当前演示身份/登录入口、明确的时间显示时区 |
| 聊天区 | 用户消息、助手答案、进度、必要追问，保留明确状态而不展示内部堆栈 |
| 客票选择卡 | 获授权旅客、航司/票价、航段、日期和状态；只展示当前可见范围 |
| 候选方案卡 | 新旧航班、相应时间和条件，说明有座信息会在确认时复核 |
| 报价卡 | 精确目标、手续费/正票价差/补税/退税/额度/服务处理、来源及 5 分钟有效期 |
| 确认区 | “确认改签”或“确认取消并按明细处理”等具体动作按钮，不能只写笼统“继续” |
| 结果卡 | 操作编号、确切结果、新订单事实及模拟收退款/额度；或审核编号/待核定原因 |
| 来源与处理记录 | 展开政策出处、允许的 PDF 页和当前有权访问的处理结果 |

用户无需先登录才能聊天；触及私有任务时给演示账户入口，登录后重新选择目标。注册/短信/证件不在本期。演示账户名单不携带账号私密订单信息。

## 资金和时间展示

所有金额来自服务端 Money，使用精确字符串格式化，浏览器不以 Number 重算汇总。分开显示应收、原路应退、本人旅行额度及不退部分；经济净变化如显示，明确与实际收退款记录不同。

例如“收 88 美元，另原路退税 5 美元”，不只显示“支付 83”。未知金额显示“待核定”。原支付渠道展示模拟标识/掩码；不允许输入新的收款人或退款渠道。

默认时间明确标 UTC，可切换显示时区；每个航班和截止时刻保留明确标识。日期输入显示所使用时区，含糊自然语言在确认前明确。倒计时仅用于显示，实际有效性由服务端接收时间判断；客户端改时间不能延长报价。

## 确认与恢复

确认按钮提交服务端报价 ID、绑定确认凭据及稳定幂等键，不提交自算金额。点击后暂禁重复点击只是体验优化，真正防重由 M4 保证。

刷新或断线后先查询当前轮次、Submission/Operation。已经完成显示原操作，不自动再确认；结果未知显示“正在核实”，提供查询按钮，不能显示失败后直接生成新写请求。明确拒绝/失效后才引导重新查询报价。

一段对话只保留一个当前可操作的报价选择；切换目标或生成替代报价后旧卡变为不可操作。历史报价可查来源但不能借旧按钮执行。5 分钟过期、身份变化或后端失效时按钮禁用，并说明重新报价原因。

处理新消息期间确认区提示“正在核对本次需求”，暂不可确认；服务端同步检查轮次状态。解释完成且方案未变时恢复仍有效报价，目标改变则显示新方案。旧提交的恢复不受报价现在是否过期影响，以已有收据/操作为准。

退出/换号清理旧选择和私有卡片；所有响应带身份/对话/轮次关联，旧响应不显示到新页面。多窗口以服务端身份为准，接收到会话变化后刷新身份与状态，不能仅依赖本地页面上残留的用户名。

## 审核、拒绝和故障

- 政策不允许时解释限制，同时显示仍可申请的权益，例如未用税费。
- 审核单持久化成功才显示编号；标明本地记录、待人工接入，金额待核定时不显示退款成功。
- 无权访问或目标不存在用同类提示，不显示其他旅客姓名/总额。
- 模型或检索失败显示已知事实与可恢复入口，已提交结果查询独立可用。
- 网络丢失不改变服务端事实，诊断日志不完整不冒充订单失败。

## 内容与访问边界

政策 PDF 引用使用服务端允许列表：知识快照、文档 ID、页码映射到固定资源；不直接把模型提供的路径交给文件服务。只提供项目政策 PDF，不开放任意本地文件读取。

对话文本默认转义，Markdown 禁止原始可执行 HTML。消息/引用中不嵌入会话密钥、模型凭据或完整支付资料。业务成功/金额卡由可信结果组件渲染，不能由任意模型 Markdown 伪造同等状态。

## 验收

游客先咨询再登录、本人/代理范围清楚、多人报价和确认对象一致、现金与额度分明、跨时区同一时刻一致、倒计时边界、重复点击、刷新/断网恢复、换号旧窗口、撤权后历史停用及不可访问编号。

浏览器自动化覆盖真实服务状态，额外人工检查窄屏、键盘焦点、加载/错误提示和政策 PDF 页码。最终 A01–A10 从网页实际输入进入，检查页面、工具及持久化共同结果，不只截图静态页面。
